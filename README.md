
# BICOBS: A Web-Based Ordering and Billing System for Taurus Bike Shop

## 📌 Project Overview

**BICOBS (Bike Shop Ordering and Billing System)** is a  web-based ordering and billing system developed for Taurus Bike Shop, located in Sandico Street, Abangan Sur, Marilao, Bulacan. The project aims to digitize and improve the shop's existing manual processes for product ordering, billing, and transaction record management.

The system is designed to provide a centralized platform where customers can browse available bicycle products and accessories, place orders, and process supported online payments. It will also assist the shop's owner and authorized staff in managing inventory, processing orders, maintaining transaction records, and generating billing information.

This project is developed as part of the requirements for the Bachelor of Science in Information Technology case study at Pambayang Dalubhasaan ng Marilao.

---

## 🎯 Project Objectives

- Develop a web-based platform for online ordering and billing.
- Improve the management of product and inventory records.
- Reduce reliance on handwritten receipts and manual transaction recording.
- Streamline order processing and payment-related workflows.
- Provide organized digital records to support business operations.
- Improve the accessibility and accuracy of transaction information.

---

## 🛠️ Technology Stack

### Frontend

- **HTML5** – Structure and content of the web pages.
- **CSS3** – Styling, layout, and responsive interface design.
- **JavaScript** – Frontend interactivity, dynamic behavior, and communication with backend APIs.

### Backend

- **Node.js** – JavaScript runtime environment for server-side development.
- **Express.js** – Backend web framework for developing APIs and handling server requests.

### Database

- **MongoDB** – Database management system for storing and managing application data, including products, customers, orders, and transaction records.
